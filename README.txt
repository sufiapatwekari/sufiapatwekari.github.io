SUFIA PATWEKARI - PORTFOLIO

FILES
- index.html: portfolio content and sections
- style.css: responsive dark/light theme styling
- script.js: typing effect, mobile navigation, theme toggle, reveal animations, active navigation and footer year
- assets/: add your profile photo and resume here

HOW TO RUN
1. Keep index.html, style.css and script.js in the same folder.
2. Add your profile image at: assets/professional photo.png
3. Add your latest PDF resume at: assets/Sufia_Patwekari_Resume.pdf
4. Open index.html in a browser, or use VS Code Live Server.

BEFORE SHARING WITH RECRUITERS
- Confirm your college's official name and the latest CGPA.
- Add your resume PDF at the exact path above; the download links already point there.
- Check that the profile photo file exists and looks professional.
- Open each GitHub and live-demo link and confirm it is publicly accessible.
- Check the phone/email details shown on the page and remove the phone number if you prefer not to publish it publicly.
- Consider adding project screenshots to each project card if you have good screenshots.

DEPLOYMENT
The folder can be deployed to GitHub Pages, Netlify or Vercel as a static site. For GitHub Pages, push the contents of this folder to the repository's publishing branch/root and enable Pages in repository Settings.
